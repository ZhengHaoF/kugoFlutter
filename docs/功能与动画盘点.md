## 零、先说判断

功能层面：**核心播放链路已经相当完整**（队列持久化、错误降级、睡眠定时、KRC/YRC 逐字歌词、
双音源混排、SMTC/托盘/任务栏进度都做了）。缺的是三类东西——

1. **规划里写了没做的**（搜索联想、倍速 UI、歌词偏移、自建歌单 CRUD）——第 1 批
   几乎一项没动，属于欠账（搜索历史已补，见 §1.1 #1）；
2. **天天会碰到却没有的**（曲目长按菜单、音量记忆 + 上次位置继续、封面淡入）——封面
   淡入已补，其余仍缺；
3. **一首成本的锦上添花**（EQ、桌面歌词、歌单备份导出）——可以先不做。

动画层面：**钱都花在了壳层和播放器**（Dock 回弹、Tab 漂移、黑胶、Hero、歌词——这几处明显
是认真调过的），第二梯队又补了封面/三态/播放键/红心/删歌，但**列表增删以外的弹层、
进度条拖拽、空态入场、队列面板仍是裸的**。全库 `AnimatedList` / `SliverAnimatedList`
/ `TickerMode` / `RepaintBoundary` / `PageStorageKey` **仍零命中**，`RefreshIndicator`
仍只有 1 处。

所以动画不是"不够"，是**覆盖面偏心**——用户每天碰十次的部分仍有一截没动。
