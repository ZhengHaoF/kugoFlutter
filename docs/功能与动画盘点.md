## 零、先说判断

功能层面：**核心播放链路已经相当完整**（队列持久化、错误降级、睡眠定时、KRC/YRC 逐字歌词、
双音源混排、SMTC/托盘/任务栏进度都做了）。缺的是三类东西——

1. **规划里写了没做的**（搜索历史/联想、倍速 UI、歌词偏移、自建歌单 CRUD）——文档自己
   都标了 ⬜，属于欠账；
2. **天天会碰到却没有的**（曲目长按菜单、音量记忆 + 上次位置继续、封面淡入）——成本不高，
   缺了总觉得糙；
3. **一首成本的锦上添花**（EQ、桌面歌词、歌单备份导出）——可以先不做。

动画层面：**钱都花在了壳层和播放器**（Dock 回弹、Tab 漂移、黑胶、Hero、歌词——这几处明显
是认真调过的），但**列表增删、图标形态、弹层、三态切换基本是裸的**。全库
`AnimatedList` / `SliverAnimatedList` / `AnimatedIcon` / `TickerMode` / `RepaintBoundary`
/ `PageStorageKey` **零命中**，`RefreshIndicator` 只有 1 处。

所以动画不是"不够"，是**覆盖面太偏心**——用户每天碰十次的列表和按钮没动，一屏万年才
看一次的歌词画廊转得飞起。补起来成本低、见效快。

### 2.2 该加动画的地方（按性价比排序）

**第一梯队 · 一天能做完、全站受益**

1. **封面 fadeIn + 占位骨架** — `cover_box.dart:112-131` 加 `FadeInImage`/`AnimatedSwitcher`，
   这是「看着不糙」的最大单点。
2. **骨架屏 → 内容 cross-fade** — `async_body.dart:27-47` 一处改，所有列表页同时受益
   （骨架淡出 + 内容淡入上移 8px，150-200ms）。
3. **封面背景渐变 lerp** — `full_player_page.dart` 切歌时整屏渐变硬切，改 AnimatedContainer
   或 TweenAnimationBuilder 做交叉淡入。
4. **空态/错误态入场** — `async_body.dart:125-156` + `common.dart:190-237` 源停用空态，
   图标+文案+按钮一行 stagger。

**第二梯队 · 每天碰得到**

5. **播放/暂停形态过渡** — 三处播放器都是 IconData 硬切换 → `AnimatedIcon(AnimatedIcons.play_pause)`；
   加载态换成 CircularProgressIndicator 也没淡入。
6. **红心缩放回弹** — `full_player_page.dart:1198`、`desktop_player_bar.dart:171`、
   `likes_page.dart:552`：一个 ScaleTransition + easeOutBack 就够。
7. **列表项删除有动画 + 可撤销** — `likes_page.dart:552`、`history_page.dart:64-77` 现在是瞬间
   消失且无撤销；换 `SliverAnimatedList` + SnackBar 撤销。和上轮 P0 的迷你条一样，属于
   「没有就觉得缺」的那类。
8. **进度条拖拽反馈统一** — 把桌面底栏的 `_isDraggingProgress` 做法搬到全屏播放页/歌词页，
   hover 放大、按下 thumb 变大。
9. **队列面板** — `queue_sheet.dart:52-98` 点一首就 `playAtIndex + pop`，无选中过渡；顺手加
   拖拽排序（唯一每天用的重排场景）。
10. **二级详情页内容 stagger 进入** — `playlist_detail_page.dart:568-580` 现在只有 Header 有 Hero，
    下面列表是 spinner → 硬切。
11. **下拉刷新** — 只有 `recommend_hub_page.dart:418` 一处有 RefreshIndicator，发现页五个 Tab、
    歌单、我喜欢、历史都没有。
12. **「到底了」提示** — 只有搜索页有 footer，其余分页没到底提示。

**第三梯队 · 观感一致**

13. **弹层转场统一** — 目前同一应用四种：`common.dart:908` 移动端系统 sheet、`:880` 桌面右滑
    240ms、`showDialog` 默认缩放淡入、`:885` 又一套。收成一种。
14. **历史页图表** — `history_page.dart:492-513` 柱子是常量 Container（无生长动画），
    `:699-740` 时段条用确定型 `LinearProgressIndicator(value:)` 不补间。
15. **主题切换过渡** — 修 `lerp` 硬跳 + 设 `themeAnimationDuration`。**注意**：`root_shell.dart:226`

    两件事要一起做，否则会出现「渐变过程中迷你条闪一下」。
16. **歌词「回到当前行」按钮** — 我上轮加的 `_ResumeFollowChip` 现在是凭空出现/消失，加个淡入。
17. **SnackBar 1 秒太短** — `fm_page.dart:85-90`、`history_page.dart:71-77`，且与第 7 条的撤销联动。

## 三、建议的排期

**第 2 批（2-3 天）· 天天碰得到的动效**

风险项，随时可以做——尤其 27a，UI 指了一条不存在的路。
