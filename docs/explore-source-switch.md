# 首页「发现」音源切换评估与实施

## 评估结论

建议实施。截图对应 `ExplorePage` 首页，不是五标签的 `DiscoveryPage` 探索页面。首页原来已经通过能力接口支持酷狗和网易云，按设置中的默认源取数，但没有直接切换入口，用户容易认为只有酷狗。新增首页切源栏即可复用已有网易能力，不需要新增接口、依赖或播放引擎。

实现依据是合并后的 [PR #8](https://github.com/ZhengHaoF/overtone/pull/8) 主分支版本 `e433acc`，包括现有 `SourceFilterBar`、默认源同步逻辑及网易云的榜单、分类歌单、新歌能力。

## 交互与实现

- 页头来源文字下增加与其他页面相同的音源筛选条；两源可用时显示「酷狗」「网易云」，不提供混排「全部」。
- 仅显示已注册、已启用、发现功能未关闭且具备首页能力的源。只剩一个源时隐藏切换栏；没有可用源时保留已有停用提示。
- 初次进入采用有效默认源。点击具体源同步持久化默认源，搜索、榜单、探索等后续入口沿用；其他入口改默认源时首页仍自动刷新。
- 切换后重新加载排行榜、推荐歌单、今日热歌、新歌速递，立即清掉旧内容。缺少能力的区块仍不渲染。
- 使用递增请求代次丢弃迟到结果，覆盖「酷狗 → 网易云 → 酷狗」时旧酷狗结果覆盖新酷狗结果的同源竞态。
- 只触发一次新源请求；点击当前源不重复加载。失败保留切源栏，可重试或切回。
- 保留歌单和榜单详情的 `src` 参数及源标记，避免网易 ID 被当作酷狗 ID。
- 不主动停止、清空或替换播放队列。顶部 FM 舞台复用现有独立会话逻辑：已有 FM 会话保持自己的来源，浏览切源不等同于重开 FM。

## 验收范围

新增离线组件测试覆盖首页直接切换四块内容、默认源持久化、不重复请求、不改变播放器状态、快速来回切换的迟到请求、桌面切换后榜单详情参数、失败源切回以及运行中关闭当前源的发现功能。更新原来「首页不显示切源栏」的旧断言，保留默认源、功能开关、其他入口同步等已有回归测试。

手机布局以 420 像素宽组件测试、桌面布局以 1280 像素宽组件测试覆盖。这些测试使用假音源，不代表已经验证真实网易账号、线上网络、用户 Windows 设备或实际声音。

## 本地验证

使用与仓库 CI 相同的 Flutter 3.47.7，依赖通过 `flutter pub get --enforce-lockfile` 安装，没有修改锁文件。

- `flutter analyze --no-pub`：无问题。
- `flutter test --no-pub test/recommend_dispatch_test.dart --reporter expanded`：17 项通过，其中新增 5 项首页切源回归测试。
- `flutter test --no-pub --reporter expanded`：全量 1,174 项通过。
- `bash tool/test_package_test_release.sh`：7 项打包与拒绝校验通过。
- `git diff --check` 与两个修改 Dart 文件的格式检查通过。

## 本轮边界

不更改推荐接口语义：原有「推荐歌单」仍使用该源默认分类歌单，不将其偷偷改为登录态个性推荐。不加入第三音源、不做双源混排、不改变私人 FM 的独立播放会话。
