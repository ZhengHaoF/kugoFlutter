## 快速开始

```powershell
cd app
flutter pub get
flutter run
```

## 当前状态

- M0–M2：深色主题、三 Tab 壳、真源搜索/歌单/专辑/歌手、播放引擎（just_audio + audio_service）、歌词、登录/游客
- M3：私人 FM、封面取色、设置、我喜欢/历史、每日推荐页、排行榜列表页已完成
- M4 起步：Release APK（debug 签名）可侧载；集成测试/性能/正式签名待做
